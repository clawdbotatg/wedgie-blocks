# Blocks

Falling blocks for the [wedgie](https://wedgie.dev). Fill a row to clear it. Every 10 rows it gets faster.

## Controls

- Joystick left / right: move (hold to slide)
- Joystick down: drop faster
- Joystick up, or press it in: drop all the way
- Green (A): turn
- Grey (B): turn back
- Red (Y): pause

Score: 100 / 300 / 500 / 800 for 1-4 rows at once, times the level. 1 point per row of a fast drop, 2 per row of a full drop.

## Saves

- `best`: the best score.

## Run it

Open https://wedgie.dev/code, press **Open a folder**, pick this one. Or on a real wedgie:
`python3 wedgie.py install .`
